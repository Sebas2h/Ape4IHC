# APE 4 — Interacción Humano–Computador

Este repositorio contiene el informe académico de la APE 4 de la asignatura de Interacción Humano–Computador. El prototipo navegable de Tienda Clara acompaña el informe como demostración de una experiencia de compra accesible y sencilla.

## Prototipo

El prototipo está organizado en dos iteraciones (`v1` y `v2`) y se implementa con HTML, CSS y JavaScript sin dependencias externas. Para probar la versión más reciente, abre `v2/index.html` en un navegador. No requiere instalación ni servidor.

## Alcance de la demostración

Tienda Clara permite explorar el catálogo, consultar información y revisar el carrito. Es una demostración académica: no procesa pagos ni realiza transacciones reales.

## Interacción y accesibilidad

- Navegación principal mediante controles semánticos y nombres accesibles.
- Enlace para saltar directamente al contenido principal.
- Mensajes de estado anunciados con `aria-live`.
- Interfaz adaptable a distintos tamaños de pantalla.

## Estructura

- `Informe_APE4_UTA.docx`: informe de la actividad.
- `prototipo/v1/`: primera iteración del prototipo.
- `prototipo/v2/`: iteración ampliada del prototipo.
